# 知识图谱使用说明

## Graph view（关系图谱）

1. `Ctrl/Cmd + G` 或点击左侧「关系图谱」。

2. 过滤可试：`tag:#枢纽` 或 `tag:#学科` 或 `tag:#主题簇`。

3. 开启「箭头」更易看依赖方向（设置里 Display → Arrows）。

## Canvas

打开 [[00-索引/OpenGeoModeller-知识图谱.canvas|OpenGeoModeller-知识图谱]]：按大气 / 水圈 / 固体地球 / 枢纽分层摆放，边对应 README 相关文档关系。

## 与仓库文档的对应

| Obsidian | 仓库 |

|----------|------|

| 本库笔记 `[[学科名]]` | `学科名/README.md` |

| [[学科关系总览]] | `docs/学科关系图.md` |

| [[MOC-OpenGeoModeller]] | 根 `README.md` 建设内容索引 |

相对链接形如 ``SurfaceWater/`（仓库）` 可在 Obsidian 中跳到仓库源目录（vault 位于 `osidian/`）。

过滤 `tag:#hpc-base模块`，或打开 [[MOC-hpc-base]] / [[04-hpc-base/hpc-base-知识图谱.canvas|hpc-base-知识图谱]]。
