# GMSH

Gmsh是开源的非结构网格划分的优秀工具，在航空航天和地球科学的网格划分中占有重要地位。

下面罗列一些地球物理领域，使用Gmsh划分网格的工具和操作：

[CAD-to-Mesh](https://www.pygimli.org/_examples_auto/1_meshing/plot_cad_tutorial.html#sphx-glr-examples-auto-1-meshing-plot-cad-tutorial-py)-器械零件等的网格划分

[Meshing terrain from a .STL file with Gmsh](https://gitlab.onelab.info/gmsh/gmsh/-/blob/master/demos/api/terrain_stl.py)

[QGIS-Gmsh](https://github.com/jonathanlambrechts/qgis-gmsh/wiki)--澳大利亚大堡礁近海岸的网格划分示例

[GPS, LiDAR and GIS data to be imported to FreeCAD](https://forum.freecad.org/viewtopic.php?f=8&t=37178&hilit=geodata#p316040)
