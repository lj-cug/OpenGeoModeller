# VirtualReality

可视化、原位可视化与 VR / AR 相关文档。

## 子目录

- [ParaView](./ParaView/)：常用开源 CFD 后处理
- [Tecplot](./Tecplot/)：商业可视化软件相关笔记
- [visit-3.14.0](./visit-3.14.0/)：VisIt 可视化
- [In-situ-Visualization](./In-situ-Visualization/)：在线 / 原位可视化（Catalyst、SENSEI、Ascent、ADIOS、VisIt 等）
- [AR-Sandbox](./AR-Sandbox/)：增强现实沙盘，用于地球科学教学
- [High-Order-Viz](./High-Order-Viz/)：高阶数值格式（如 DG）结果可视化
- [Oculus-Quest](./Oculus-Quest/)：VR 设备与 ParaView 连接
- [Computer_Graphics](./Computer_Graphics/)：OpenGL、VTK、离屏渲染等计算机图形学基础
